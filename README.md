# GJShop — Professional Shopping UI Prototype v2

Responsive mobile-first static storefront inspired by modern ecommerce usability patterns, with original GJShop branding.

## Features
- Search, categories, deal and top-rated filters, sorting
- Demo wishlist and cart with browser localStorage
- Responsive mobile bottom navigation and desktop header
- Accessible labels and demo disclosure
- PWA manifest/service worker (installability depends on hosting and browser)

## Important limitations
All product names, prices, ratings and discounts are **fictional sample data**. There is no backend, login, checkout, live inventory, affiliate API, AI model, or advertising integration. The cart is a demo only. Do not advertise prices as real.

## Publish
Upload all files in this folder to a GitHub Pages repository root and enable GitHub Pages from main / root. Then open the GitHub Pages URL. GitHub Pages requires no server for this demo.
